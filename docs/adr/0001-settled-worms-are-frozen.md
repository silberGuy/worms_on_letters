# Settled Worms are frozen

A Worm that has come to rest never moves or changes shape again, and later Worms land on it as if it were solid, even though shared physics would make piles squash and shift more realistically. This is a composition tool, so a Worm the user has approved must stay where it is, and frozen Worms also leave the simulation, which allows far more Worms in a Composition.
